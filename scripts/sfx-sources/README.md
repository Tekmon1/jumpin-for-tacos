# External SFX source recordings

This directory contains the exact public high-quality Freesound audition previews used as deterministic source layers by `scripts/generate-sfx.mjs`. They are not runtime assets and are not described as original Jumpin For Tacos recordings.

Selected recordings:

- `445118__breviceps__cartoon-splat-hq-preview.mp3` — Breviceps, “Cartoon - Splat!”, Freesound sound 445118, CC0 1.0.
- `789390__modusmogulus__airplane-propeller-loop-hq-preview.mp3` — modusmogulus, “Airplane Propeller Loop”, Freesound sound 789390, CC0 1.0.
- `251971__clif_creates__propeller-plane-hq-preview.mp3` — clif_creates, “Propeller Plane”, Freesound sound 251971, CC0 1.0.

Complete source URLs, original filenames, hashes, acquisition dates, attribution requirements, candidate disposition, and modifications are generated into `public/game/assets/sfx/sfx-manifest.json` and summarized in `docs/sfx-remaster-phase3.md`.
